# SonarQube Estudo

![CI](https://github.com/pitombeira00/sonarqube-estudo/actions/workflows/ci.yaml/badge.svg)
![Cobertura de Código](https://codecov.io/gh/sonarqube-estudo/branch/main/graph/badge.svg)

Este projeto é um estudo sobre a integração de ferramentas de análise de código e testes automatizados utilizando PHP, PHPUnit e GitHub Actions.

## Funcionalidades
- Implementação de testes unitários com PHPUnit.
- Integração contínua (CI) configurada com GitHub Actions.
- Gerenciamento de dependências com Composer.
- Configuração de cobertura de código e análise de qualidade.
